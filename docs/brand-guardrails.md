# Brand guardrails

Arctic Fresh is **Inuit-operated**, serving 15 Nunavut communities. Generic Arctic/Northern design tropes — many of which originate in southern marketing or non-Inuit cultures — actively damage credibility. Read this before making brand-surface decisions.

## Don't

- **No totems.** Totems are a West Coast First Nations art form, not Inuit. Using them is a geographic/cultural mistake that signals zero homework.
- **No igloos, sled dogs, or Arctic-explorer iconography**, even as "cute" illustrations. These are exoticizing tropes from southern marketing.
- **No "tribal-styled" or decorative fonts.** Stick to clean sans.
- **No earth-tone overload.** Browns, ochres, kraft-paper aesthetics — none of these are the Nunavut visual register.
- **No "you saved $X" splash on subsidized prices.** See `docs/nnc-display.md`.

## Do

- **Use real Nunavut photography** sourced from the client (community life, kitchens, food in context) — beats Arctic stock every time.
- **Restrained palette** — the current mint/forest/coral set is on-pattern with how Inuit-run brands handle color: clean, place-evocative, low saturation.
- **Sans-serif typography**, matching the visual register of every confirmed Inuit-run brand.
- If syllabics (ᐃᓄᒃᑎᑐᑦ) ever ship, use them functionally (real bilingual labels, validated with the client) — never as decoration.

## Reference brands

Inuit-operated or Government of Nunavut official styles, useful as design language reference: **Canadian North**, **Air Inuit**, **Government of Nunavut**, **Inuit Tapiriit Kanatami**, **Arctic Co-operatives Limited**.

When uncertain, defer to the client and propose visual choices in `playground/` for review before committing them to live theme code.
